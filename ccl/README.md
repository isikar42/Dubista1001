# Dubista1001 Portfolio Workspace

This workspace is set up as a starter portfolio and project hub for a student internship and portfolio process.

## Included sections

- Portfolio
- Beoordelingsformulieren
- Stageonderzoek

## Quick start

Open the landing page in a browser:

1. Open [index.html](index.html) in a browser, or
2. Run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Notes

This project is intentionally lightweight and easy to extend. You can add your own project pages, reflection notes, and stage documents as the portfolio grows.
